# LapisCV 内容规范

用户不需要写 Markdown。AI 构建并维护以下源格式：

| 元素 | 用途 |
| --- | --- |
| `# 姓名` | 仅一个顶层标题，真实姓名 |
| `> 联系方式` | 手机、邮箱、城市、主页，缺失项省略 |
| `## 栏目` | 任意有实际资料的栏目 |
| `### 条目名称` | 公司、学校、项目或奖项名称 |
| 普通段落、`- 要点` | 说明和成果 |
| `**重点**`、`*强调*`、行内代码、链接 | 少量强调、技术名词和作品地址 |
| `---` | 强制从下一页开始；默认由渲染器自动分页 |

原版名称与日期的左右排版使用：

```html
<div class="entry-title">
<h3>公司 / 岗位、学校 / 专业、项目名称</h3>
<p>真实的起止时间</p>
</div>
```

`detail` 不必是年月区间，允许年份、单一获奖日期、现任、至今或其他真实补充信息。不需要时间时省略右侧 `<p>`。原版 `div alt="entry-title"` 也兼容。

常用图标：教育 `&#xe80c;`、工作 `&#xe618;`、项目 `&#xe635;`、技能 `&#xecfa;`；联系人手机 `&#xe60f;`、邮箱 `&#xe7ca;`、主页 `&#xe600;`。未知栏目无需强配图标。标题中直接使用图标实体，或用 `<span class="icon">...</span>` 包裹。

不使用表格、代码块、四级及更深标题、嵌入网页、表单、样式或脚本。不要生成图片与头像；这些由浏览器本地管理。Markdown 渲染结果仅允许有限的排版标签和外链，其他内容被过滤。

手动分页置于完整条目或栏目之间，不在名称和描述之间插入。实际字体、照片和主题决定行高，因此不得按字符数猜测准确页数。

特殊文本中的 `<`、`>`、`&` 用 HTML 实体表示，避免被当成标签；普通 Markdown 语法字符按文字含义转义。保留换行的普通段落可用 `<br>`，不要把 HTML 写进代码围栏。
